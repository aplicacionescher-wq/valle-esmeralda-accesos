# Proyecto Valle - Control de Accesos

## 🚀 Cómo usar

1. Instalar servidor local:
   npm install -g serve

2. Ejecutar:
   serve .

3. Abrir en navegador:
   http://localhost:3000

## 🔥 Firebase
Configurar reglas temporales:

allow read, write: if true;

## 📦 Deploy
Subir directamente a GitHub Pages o Firebase Hosting.
